# 北區會堂兒崇點數系統 (Kids Score System)

這是一個專為教會兒童主日學（小寶、中寶、大寶）設計的點數管理系統。系統採用現代化的前端網頁技術，結合 Google Firebase Firestore 資料庫，提供一個畫面乾淨且操作直覺的管理平台，支援手機與平板裝置，實現了孩童簽到、上課加分表揚、點數兌換、老師關懷與升級管理等功能。

## 🎨 UI 與設計語言 (v2 版更新)

整個系統經過重新設計，採用類似 Airbnb 的現代極簡風格 (Airbnb-Style)：
- **乾淨白底**：以純白色背景加上淡灰圓角卡片與陰影呈現層次，帶來輕盈感。
- **現代字型**：匯入 `Inter` 字體，文字顯示俐落清晰。
- **行動裝置優先 (Mobile-First)**：
  - 手機版會自動將主要導覽列轉換為「底部標籤列 (Tab bar)」，方便單手觸控。
  - 平板與電腦端則維持頂部標籤顯示。
- **觸控優化**：所有簽到按鈕與印章加分元件，皆放大為適合點擊且帶有觸控回饋動畫的按鈕。

## 🚀 系統核心功能

### 1. 首頁 (`index.html`)
- 提供大寶 (小四~小六)、中寶 (小一~小三)、小寶 (幼稚園) 三個組別的入口卡片。
- 選定組別後，系統會透過 URL 參數 (`?group=...`) 在各分頁間傳遞，保持操作連貫。

### 2. 今日點名 (簽到系統 `signin.html`)
- **出缺席管理**：至資料庫自動抓取該組別「今日尚未簽到」的名單。
- 畫面上按原本所屬的組別區塊列出色彩直覺的按鈕，點擊名字即立刻觸發簽到。
- 若特定學生被設為「隱藏」或已升級為「新世代」，他們將不會顯示在這個點名畫面上。

### 3. 加分評分 (`score.html`)
- **卡片式操作**：以個別學生的專屬卡片列出，卡片即時顯示「累計點數」與「今日點數」。
- **觸控蓋章體驗**：
  - 提供：準時 (+3分)、專心敬拜 (+2分)、搬椅子 (+1分)、小組討論 (+1分)。
  - 點擊對應格子即可幫學生「蓋章」或「取消蓋章」，點數會及時增減。
- **額外加點**：在每張卡片底部提供自訂點數微調欄位。

### 4. 新朋友報到 (`newfriend.html`)
- 透過直覺的圓角選項按鈕，可以快速幫新來的小朋友建立資料。
- 註冊後將立即在資料庫的主集合（`kids`）建立檔案。系統有防呆檢查，如果名字已經存在會主動提示並阻止重複建立。

### 5. 管理員工具 (`manager.html`)
- **切換組別**：直接於畫面上的一鍵按鈕無縫切換目前正在管理的組別。
- **關懷系統**：系統自動回推 8 週的聚會紀錄，並按照「X週未出現」作摘要分類顯示，非常方便老師即刻掌握誰需要打電話關懷。
- 將操作引導至「換點數」與「升降級」頁面。

### 6. 換點數 (`shop.html`)
- 點數兌換市集時的必備工具。
- 專注於名字與現有點數，只需輸入想要扣抵的數字，確認後即結帳。系統內建防呆阻止因餘額不足導致扣成負數。

### 7. 兒童升降級 (`upgrade.html`)
- 一鍵幫助孩童完成年級轉換：
  - **升級**：小寶 ➡️ 中寶 ➡️ 大寶 ➡️ 新世代。
  - **降級**：當操作失誤時的補救方案。
- **隱藏 (✖)**：長期不出席或暫停參與的孩童，組別將標為隱藏，不再占據前台點外名單，維護畫面簡潔（管理員可至 Firebase 後台手動復原）。

## 🛠️ 架構與部署

- **前端**：純 HTML5, Vanilla JavaScript, CSS3
- **圖示庫與元件庫**：無依賴龐大框架，輕量化純 CSS 手刻 UI。
- **資料庫**：Google Firebase Firestore
  - 在 `init_firestore.js` 中需填寫正確的 Firebase API Key，且確保 Firestore Database Rule 設為允許讀取與寫入即可運作。
  - 將整個專案資料夾部屬到靜態網頁主機 (如 GitHub Pages, Vercel 或直接存放在手機端檔案中皆可執行)。
